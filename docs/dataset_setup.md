# Dataset Setup Guide

## Option 1 — Synthetic data (default, no download needed)
The project auto-generates realistic synthetic CSI data. Just run any script and it works immediately.

## Option 2 — FallDeFi dataset (real WiFi fall detection data)
```bash
cd data/
git clone https://github.com/dmsp0/FallDeFi .
```

## Option 3 — Widar 3.0 (full gesture dataset)
Download from: http://tns.thss.tsinghua.edu.cn/widar3.0/
Place files in `data/widar3/`

## Option 4 — UT-HAR (human activity recognition)
```bash
cd data/
wget http://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz  # placeholder
```
See the UT-HAR paper for actual download link.
